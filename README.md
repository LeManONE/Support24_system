## 📌 О проекте

Веб-сервис для автоматизации работы техподдержки в **локально-вычислительной сети предприятия**.  
Позволяет пользователям оставлять заявки 24/7, отслеживать статус решения, а администраторам комфортно отвечать на вопросы и решать проблемы.

> [!NOTE]
> **Почему это актуально?**  
> *[К сожалению во многих организациях локальная тех.поддержка осуществляется через мессенджеры, что создает огромное множество проблем. я попытался решить эту проблему..]*

---

## 🎯 Цели дипломного проекта

- Снизить время реакции на инциденты в ЛВС.
- Создать единое окно для приёма заявок.
- Внедрить ролевую модель: *пользователь → администратор ЛВС*.
- Обеспечить работу без доступа к внешнему интернету (локальная установка).
