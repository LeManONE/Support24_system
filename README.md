## 📌 О проекте

**Support24 System** — это веб-приложение, которое автоматизирует процесс обработки заявок пользователей. Проект разработан в рамках дипломной работы и включает в себя:

- 👨‍💼 **Панель администратора** для управления заявками и пользователями.
- 👤 **Личный кабинет пользователя** для создания и отслеживания тикетов.
- 📊 **Система мониторинга** клиентских машин (Prometheus + Grafana).
- 🐳 **Контейнеризация** базы данных MySQL.

---

## ✨ Возможности

### Для администратора
- ✅ Управление заявками (просмотр, изменение статуса, ответ, удаление).
- ✅ Управление пользователями (CRUD, сброс пароля).
- ✅ Фильтрация и поиск по тикетам и пользователям.
- ✅ Пинг IP-адреса компьютера пользователя.
- ✅ Полное логирование всех действий в системе.
- ✅ Встроенные графики статистики по заявкам.

### Для пользователя
- ✅ Создание новых заявок с указанием приоритета.
- ✅ Просмотр истории обращений и статуса текущих тикетов.
- ✅ Получение ответов от администратора в самом веб-сервисе.
- ✅ Раздел "Частые вопросы" со статьями.

### Технические особенности
- ✅ Автоматический установочный скрипт для Ubuntu Server.
- ✅ Изолированная работа базы данных в Docker.
- ✅ Гибкая система фильтрации и поиска.
- ✅ Поддержка UTF-8 и русского языка.

## 🚀 Быстрая установка

### Требования
- Сервер под управлением **Ubuntu 22.04** или **24.04**.
- Доступ в интернет для скачивания пакетов.
- Права **root** или возможность выполнения `sudo`.

### Установка в одну команду

Просто выполните эту команду на своём сервере:

```bash
curl -sSL https://raw.githubusercontent.com/LeManONE/Support24_system/main/install.sh | sudo bash
```

#### Скрипт автоматически:

1. Установит Apache, PHP 8.3, Docker и другие зависимости.
2. Загрузит код из репозитория.
3. Запустит MySQL в Docker-контейнере и создаст базу данных.
4. Настроит виртуальный хост и права на файлы.
5. Добавит все сервисы в автозапуск.
